# Участие в aiagent

Автор и владелец основного репозитория: **Кислов Роман Сергеевич** (@rkislov).

Прямую запись и слияние изменений в основной репозиторий выполняет только владелец. Остальные участники могут создавать issues и отправлять pull requests из своих форков. Решение о принятии PR остаётся за владельцем; создание PR не даёт прав на запись.

1. Опишите ошибку или предложение в issue без паролей, токенов и личных данных.
2. Для изменения создайте fork и отдельную ветку.
3. Добавьте проверки поведения, выполните `pip install -e '.[test]'` и `pytest -q`.
4. Для изменений интерфейса выполните `cd frontend && npm ci && npm run build`.
5. Отправьте PR с описанием изменения и результатов проверок.

Вклад принимается под Apache License 2.0. Эти правила относятся к доступу к основному репозиторию и не ограничивают права на использование и модификацию собственных копий, предоставленные лицензией.

Не добавляйте config.yaml, data/, .env, ключи, токены, базы авторизации и пользовательскую переписку. Для тестов используйте искусственные данные и временные каталоги.
